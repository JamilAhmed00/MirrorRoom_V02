# SPYIT Design Architecture Documentation Directory

Welcome to the design documentation folder for **SPYIT Fresh Fruit Dynamic Soda**.

## Files in this Directory

- [`DESIGN_ARCHITECTURE.md`](./DESIGN_ARCHITECTURE.md) — The comprehensive design system and architecture manual. Contains:
  - Complete Brand Identity & Design Tokens (HEX color matrices, Typography hierarchy, Lucide icons, elevation & shadows).
  - Kinetic Motion, Physics & Animation Rules (Wave marquees, Parallax fruit slices, Can hover physics, Bubble animations).
  - Responsive Grid & Layout Systems (Breakpoints, spacing math, container constraints).
  - Section-by-Section Blueprints & Component Hierarchies.
  - State Management & TypeScript Data Models.
  - Step-by-Step Blueprint for designing new pages adhering to this design system.
  - Anti-Patterns & Quality Standards.

- **Sun Orange:** Background `#E35205`, Accent `#FF8A00`
- **Electric Kiwi:** Background `#5F9E17`, Accent `#A3E635`
- **Wild Strawberry:** Background `#CE1141`, Accent `#FB7185`
- **Royal Grape:** Background `#6B2D8C`, Accent `#C084FC`

### Typography Stack
- **Headings & Brand:** `Cabinet Grotesk` (Weight 700-900), `Anton`, `Bebas Neue`
- **Body & Controls:** `Inter`, `DM Sans`, `Cabinet Grotesk` (Weight 400-600)
- **Signature Accents:** `Satisfy`, `Alex Brush`

### Key Easing Curve
- `cubic-bezier(0.16, 1, 0.3, 1)` (1000ms for flavor transitions, 300-500ms for micro-interactions)
